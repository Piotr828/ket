# KET
KET to projekt naukowy prowadzony w Kole Studentów Informatyki UWr.
Głównym celem KET jest poprowadzenie uczestnika od pierwszego kontaktu z właściwościami pojedynczego kubitu aż po samodzielną implementację i uruchomienie autorskiego algorytmu na rzeczywistym procesorze kwantowym.
W tym repozytorium publlikowane będą wszelkie programy, które ze względów technicznych wymagają hostowania lub istotnie na nim zyskają
